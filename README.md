# BS ClubIn

동아리의 행사 신청과 출석 관리를 위한 1인 개발 웹 서비스입니다.

## 개발 목적

- 동아리 행사 신청 및 출석 관리의 불편함 해결
- Spring Boot 백엔드 개발 경험
- GitHub 기반 협업 과정 연습
- Swagger를 활용한 API 명세 관리

## 개발 기간

2026.07.27 ~ 2026.08.01

## 개발 형태

1인 개발 · AI-assisted UI/Frontend

## 핵심 기능

- 회원가입 및 로그인
- 행사 등록 및 조회
- 행사 참가 신청 및 취소
- 신청자 및 출석 관리
